# Privacy

Route Regression Check runs locally in the Unity Editor. The package contains no telemetry, analytics, account login, advertising, network client, external AI service or license server. It reads the selected suite, the current scene's navigation and project metadata necessary for the check.

Reports are written only when you choose to export. They include project-relative scene and suite paths, route names, coordinates, navigation measurements, the Unity version and a timestamp. They do not contain an absolute home-directory path or a machine identifier by design. Review a report before sharing it outside your organization.

The package does not change Unity's own services or privacy settings. Unity Editor and Asset Store account data remain subject to Unity's policies.

Support information is whatever you choose to send to BizzKitt BV at hello@bizzkitt.ai. Use a minimal synthetic reproduction and avoid confidential project assets and personal data.
