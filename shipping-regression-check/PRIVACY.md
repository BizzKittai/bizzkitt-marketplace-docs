# Privacy and data handling

Shipping Regression Check runs inside the WordPress installation where it is installed. BizzKitt BV receives no telemetry, selected products, test cases or reports automatically. There is no remote AI or analytics service in this plugin.

The plugin reads the fixture products and relevant shipping/platform settings needed to calculate supported rates and invalidate old reports. It stores a suite and latest report in two local WordPress options. A report contains test IDs, method IDs, amounts, a zone ID, timestamps, platform versions, status and a configuration fingerprint. Exports also include the saved fixture SKU and destination codes. Use fictional data and review exports before sharing. No order is created or read for validation.

WordPress, WooCommerce, hosting and other installed extensions have their own behavior and privacy terms. The plugin does not disable all of their network activity. It blocks WordPress HTTP calls only during its core calculation; this is not a sandbox for third-party PHP.

The Delete saved data button and plugin uninstall remove its two stored options. Backups and downloaded reports are under your control. Deactivation retains saved data.
