# Release Boundary Check privacy notice

BizzKitt BV provides this local developer tool. The plugin reads only the archive and policy selected by the user. It does not send files, archive names, contents, reports or telemetry to BizzKitt or an AI service. It does not execute entries.

Nested archive bytes are temporarily written to operating-system temporary files for ZIP validation and deleted after inspection; cleanup can fail if the process or computer stops. No archive entry path is extracted onto the filesystem.

Exported reports contain entry names, policy patterns, rule identifiers and input SHA-256 hashes. These can reveal sensitive metadata. Reports do not include file contents or absolute input paths. Review a report before sharing it. A report is a point-in-time result, not a certification or a complete secret/security scan.

JetBrains separately processes account, licensing, purchase and installation data under its own notices. Marketplace activation is not yet tested for this product.
